# 🚀 Featured Project

## LabourLink

### Migrant Workers Management System

**LabourLink** is a full-stack web application developed to support
migrant workers and improve the management of employment-related
services.

The system provides different portals for different users:

| Portal               | Purpose                              |
| -------------------- | ------------------------------------ |
| 👷 Worker Portal     | Submit and manage worker complaints  |
| 🔎 Job Seeker Portal | Search and apply for available jobs  |
| 🏢 Agency Portal     | Publish and manage job opportunities |
| 🛡️ Admin Portal     | Manage the overall system            |

### ✨ Key Features

* 🔐 Authentication & Authorization
* 👥 Role-based user access
* 🔎 Job searching
* 📋 Job posting & management
* 📝 Job applications
* ⚠️ Worker complaint management
* 🔌 REST API integration
* 🗄️ Database management
* ☁️ Cloud deployment
